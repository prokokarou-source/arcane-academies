# Sounds, Music and Haptics Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Sound effects, a music loop and Android haptics for the Arcane Academies client, controlled by Settings.

**Architecture:** A pure cue function turns client state changes into cue names; a `SoundBoard` plays cues
(HTMLAudioElement behind an injectable backend) and vibrates, gated by prefs; a React hook in `App` connects them.
Audio files are CC0 and live in `public/sounds/`.

**Tech Stack:** React 18, Vite 5, vite-plugin-pwa (Workbox), Vitest + RTL.

**Spec:** `docs/superpowers/specs/2026-11-13-sounds-design.md`

## Global Constraints
- UI text English only, in `src/i18n/strings.ts`.
- Only CC0 audio; every file listed in `public/sounds/CREDITS.md` with source URL and pack name.
- No sound before the first user gesture; music paused while `document.hidden`.
- `npm test`, `npm run typecheck`, `npm run build` green.

## Review Focus
- Reconnect/rejoin delivers a game message for the same turn → no repeated "new turn" cue (test in Task 2).
- Old saved prefs `{ sound: false }` → both music and sfx off (test in Task 1).
- `navigator.vibrate` missing (iOS) → no error (test in Task 3).
- `audio.play()` rejects (autoplay blocked) → swallowed, no unhandled rejection (test in Task 3).
- Leaving a game to Home → music keeps playing, no restart from 0 (test in Task 3: `music(true)` twice starts once).

- [ ] Tests: lobby seats 2→3 → `['join']`; lobby→game → `['start']`; game turn key (term/turn/phase) changes while picking → `['turn']`, same key again (rejoin) → `[]`;

### Task 3: SoundBoard

**Files:** Create `src/audio/sounds.ts`; Test `test/sounds.test.ts`.

**Produces:** `interface AudioBackend { create(src: string): { play(): Promise<void> | void; pause(): void; volume: number; loop: boolean; currentTime: number } }`;
`createSoundBoard(opts: { backend: AudioBackend; vibrate?: (p: number | number[]) => boolean; doc: { hidden: boolean; addEventListener(t: 'visibilitychange', f: () => void): void } })`
returning `{ unlock(): void; play(c: Cue): void; music(on: boolean): void; setPrefs(p: Pick<Prefs,'music'|'sfx'|'haptics'>): void }`.
Files: `/sounds/<cue>.mp3`, music `/sounds/music.mp3` (loop, volume 0.35). Haptic patterns: select 10, build/tower/sell 20, duelWin/victory [30,40,60], duelLoss 80.

- [ ] Tests: nothing plays before `unlock()`; `sfx:false` → no play; `haptics:false` or no `vibrate` → no vibrate and no throw; rejected `play()` is caught;
  `music(true)` twice → one start; hidden → music paused, visible → resumed if on; `setPrefs({music:false})` pauses music.
- [ ] Implement, test, commit.
